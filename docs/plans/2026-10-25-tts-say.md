# `awtrix_ng.say` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сервіс `awtrix_ng.say` озвучує текст рушієм TTS Home Assistant на годиннику TC002 без токена.

**Architecture:** HA генерує mp3 (`tts` + `media_source`), сервіс будує адресу, доступну годиннику, і надсилає `{"file": url}` на `/api/v1/audio/play` через наявні `AwtrixService.call()` і `AwtrixNgApi.async_play_sound`. Нових шарів нема.

**Tech Stack:** Python 3.14, Home Assistant 2026.11, pytest-homeassistant-custom-component (`asyncio_mode=auto`).

**Spec:** `docs/specs/2026-10-25-tts-say.md`

## Global Constraints

- Рівно один із `name`, `rtttl`, `builtin`, `file` в `async_play_sound` (інакше `ValueError`).
- Ліміт mp3 годинника 4 МБ: довжину не перевіряємо, лише рядок у описі сервісу.
- `manifest.json`: `after_dependencies: ["tts", "media_source"]`, `dependencies` лишається `[]`.
- Не змінювати наявні сервіси, `notify`, `speech`. Без кешу, черги, гучності.
- Помилки HA (`ServiceValidationError`, немає рушія) віддаються як є. Помилки годинника йдуть через `call()` (лог + `False`).
- Додавання сервісу = ім'я + схема + поля + target в `const.py` і однойменний метод в `awtrix.py`.

## Review Focus

- `engine` порожній і немає рушія за замовчуванням: `ServiceValidationError` доходить до користувача, на годинник нічого не шлеться.
- `internal_url` не задано: беремо `config.url` з годинника, не зовнішню адресу.
- Годинник недоступний на `/api/v1/voice`: фолбек на `get_url(hass)`, а не падіння.
- `options` не словник: схема відхиляє.
- Кілька пристроїв: mp3 генерується один раз, а не на кожен годинник.

### Task 2: сервіс `say`

**Files:**
- Modify: `custom_components/awtrix_ng/const.py` (`SERVICE_SAY`, `SERVICES`, `SERVICE_SAY_SCHEMA`, `SERVICE_SAY_FIELDS`, три таблиці)
- Modify: `custom_components/awtrix_ng/awtrix.py` (`say`, приватний `_tts_url`)
- Modify: `custom_components/awtrix_ng/manifest.json`
- Test: `tests/test_say.py`

**Interfaces:**
- Consumes: `AwtrixNgApi.async_play_sound(file=...)`, `async_get_voice()` з Task 1; `AwtrixService.call`, `AwtrixService.api`.
- Produces: `AwtrixService.say(data: dict[str, Any]) -> dict[str, Any]`.
  `SERVICE_SAY_SCHEMA = SERVICE_BASE_SCHEMA.extend({Required("message"): str, Optional("engine"): str, Optional("language"): str, Optional("options"): dict})`.

- [ ] **Step 1: Тести** (`hass` fixture, патч `tts.media_source.generate_media_source_id`, `media_source.async_resolve_media`, мок coordinator через `AwtrixService.api`):
  - `test_say_sends_file_url`: `async_resolve_media` повертає `PlayMedia(url="/api/tts_proxy/abc.mp3", mime_type="audio/mpeg")`, `internal_url="http://192.168.88.10:8123"`. Годиннику йде `async_play_sound(file="http://192.168.88.10:8123/api/tts_proxy/abc.mp3")`.
  - `test_say_passes_engine_language_options`: аргументи доходять до `generate_media_source_id(hass, message, engine, language, options)`.
  - `test_say_without_internal_url_uses_watch_config_url`: `internal_url=None`, `async_get_voice` повертає `{"config": {"url": "http://192.168.88.10:8123"}}`; використано цю адресу.
  - `test_say_voice_lookup_fails_falls_back_to_get_url`: `async_get_voice` кидає виняток; використано `get_url(hass)`.
  - `test_say_no_engine_raises`: `generate_media_source_id` кидає `ServiceValidationError`; він виходить назовні, `async_play_sound` не викликається.
  - `test_say_generates_once_for_many_devices`: два coordinator, `generate_media_source_id` викликано один раз, `async_play_sound` двічі.
  - `test_say_schema_rejects_non_dict_options`: `SERVICE_SAY_SCHEMA({"device_id": ["x"], "message": "hi", "options": "no"})` дає `vol.Invalid`.
- [ ] **Step 2:** `pytest tests/test_say.py -v` — FAIL (`SERVICE_SAY` не існує).
- [ ] **Step 3:** `const.py`: додати за зразком `SERVICE_SOUND`; у `SERVICE_SAY_FIELDS` описати `message`, `engine` (selector `entity` domain `tts`), `language`, `options`, `device_id`, в описі `message` згадати ліміт 4 МБ. `awtrix.py`: `say` генерує id (`tts.media_source.generate_media_source_id`), резолвить (`media_source.async_resolve_media(hass, id, None)`), будує повну адресу в `_tts_url(url, coordinators)`, далі `self.call(lambda x: x.async_play_sound(file=url), coordinators)`. `_tts_url`: відносну адресу пропускає через `async_process_play_media_url(hass, url, allow_relative_url=True)`, базу бере по черзі: `get_url(hass, allow_external=False)`, `config.url` з `async_get_voice()` першого годинника, `get_url(hass)` (з записом у лог). Імпорти `tts`/`media_source` робити всередині `say` або через `after_dependencies`-безпечний шлях, щоб без цих інтеграцій компонента вантажилась.
- [ ] **Step 4:** `manifest.json`: `"after_dependencies": ["tts", "media_source"]`.
- [ ] **Step 5:** `pytest -v` (весь набір) — PASS.
